# Kökzhol — landing page previews (temporary GitHub Pages host)

Canonical production domain: https://kokzhol.kz/ (to be secured). These previews carry
`<meta name="robots" content="noindex, follow">` and a canonical to the production domain, so they are
not indexed. **At go-live** replace that meta with
`<meta name="robots" content="index, follow, max-image-preview:large, max-snippet:-1">`,
point `og:image` / `primaryImageOfPage` at the production domain, and submit `sitemap.xml`
in Google Search Console and Bing Webmaster Tools.

| Variant | Path | What it is |
|---|---|---|
| C | `/` | 3D scenes (Three.js r128 from cdnjs, code-built geometry) |
| B | `/b/` | CSS/SVG motion only, no WebGL |
| D | `/d/` | Adaptive: 3D on a fast connection and capable device, B scenes on a slow one; `?mode=lite` / `?mode=3d` override; falls back to lite if Three.js does not load within 8 s |

All three share one source (variant C) and the same content, CI tokens and RU strings.
Language: `?lang=en` / `?lang=ru`; default from the visitor's browser language, remembered in localStorage.

## SEO / GEO / AEO / LLM layer
- `<title>`, meta description, canonical, hreflang en/ru/x-default, Open Graph + Twitter card, `og-image.png` 1200×630
- One JSON-LD `@graph`: Organization, WebSite, WebPage (dateModified, speakable), Service with offer catalogue,
  LocalBusiness ×2 (city only, no street address), FAQPage generated from the visible FAQ, HowTo, DefinedTermSet (GDP glossary)
- Answer-first paragraph under the H1; FAQ questions as `<h3>` with the first one open; 10 answers of 40–62 words
- `robots.txt` (AI crawlers listed explicitly), `sitemap.xml`, `llms.txt`, `llms-full.txt`, `site.webmanifest`
- Claim rules: no superlatives, future facts carry «from launch» / «in preparation», no hub addresses, no founder or manufacturer names

## Build (from the workspace folder, Python 3)
```
python build-seo.py                       # base-c.html -> site/index.html (+ site files)
python build-b.py  site/index.html site/b/index.html kokzhol-b-animated.html chk-b.js
python build-d.py  site/index.html site/d/index.html kokzhol-d-adaptive.html chk-d.js
python seo-check.py site/index.html site/b/index.html site/d/index.html
```
Content lives in `seo_content.py` (EN/RU pairs). `base-c.html` is the pre-SEO variant C page.

## Go-live switch (added 02.11.2026)
Rebuild with the production flag, then rebuild B and D from the result:

    python build-seo.py --production
    python build-b.py site/index.html site/b/index.html kokzhol-b-animated.html chk-b.js
    python build-d.py site/index.html site/d/index.html kokzhol-d-adaptive.html chk-d.js

`--production` sets `<meta name="robots" content="index, follow, …">` and points og:image to https://kokzhol.kz/.
Contact channels live in one object in the page script: `const CONTACT={tg,wa,mail,endpoint}`; fill the four values at launch.
The example temperature report is generated by `mk-report.py` → `site/assets/temp-report-sample.html` → PDF via headless Chrome.

## P2 / P3 layer (added 02.11.2026)
- `#pricing` (end of the network section): pricing basis per lane type, what is included, what is charged separately, «fixed price» = per box and city for a calendar quarter. No tariff numbers until approved.
- Packaging catalogue under `#temperatures`: four box classes + pallet shipper; hold-time column stays «after qualification» until the summer and winter runs are done. Schema: `ItemList` of `Product`.
- Reverse flows (returns, recalls, quarantine, destruction) in `#gdp`; cargo insurance and operational-figures rows in the key-facts table.
- Segment anchors `#labs`, `#pharmacies`, `#plants`, `#intersite` (+ `#trials`) with a jump strip, one question per card; all questions are in the FAQPage schema (25 Q&A now, 40–62 words each).
- `#digest`: regulatory digest, four dated notes with primary sources, `Article` schema each. Add a note = add a row to `DIGEST` in `seo_content.py`.
- `track/`: shipment-tracking page (noindex), demo ID `KZ-2026-1215-00731` until launch; `Service.potentialAction` = `TrackAction` with `track/?id={shipment_id}`.
- Tender-readiness kit in `#quality` (ten documents with status) + PDFs. `mk-docs.py` writes `assets/kokzhol-fact-sheet-{en,ru}.html` and `assets/kokzhol-tender-checklist-{en,ru}.html` from the same content source; render to PDF with headless Chrome:
  `chrome --headless=new --disable-gpu --no-pdf-header-footer --print-to-pdf=<out.pdf> http://127.0.0.1:8765/assets/<name>.html`
  Links carry class `doc-lang`; the language switch swaps `-en.pdf` / `-ru.pdf`.
- Case studies (`CASES`) and partner logos (`PARTNERS`) are empty lists in `seo_content.py`; the page shows a dated note until the first entries exist (client consent required).
- Ops: `tools/live-check.py <base url>` checks every public path, canonical, JSON-LD, FAQ count and TLS expiry (≥ 21 days); `.github/workflows/live-check.yml` runs it weekly and on push. Change `SITE_URL` on domain day.
- Kazakh: not built. `kk-translation-template.tsv` (workspace) lists every key with EN and RU for the translator; the page keeps «Kazakh after native-speaker review».
